# From Grapes to Wine – A Journey into Traditional Winemaking

## Project Overview

**Course:** Virtual Reality – Politecnico di Torino (2026/2027)  
**Group:** 06  
**Project:** From Grapes to Wine

### Synopsis

*From Grapes to Wine* is an educational Virtual Reality experience designed to immerse users in the traditional winemaking process.

The application allows users to explore a rural environment and discover how wine was produced before the introduction of modern industrial machinery.

Through a first-person perspective, users will experience the different stages of traditional winemaking, including crushing, devatting, storage and tasting.

The project focuses on cultural heritage, historical education, and learning through direct interaction with the environment and traditional equipment.

## Assignment 1 – Environment Blockout

The first assignment focuses on creating a blockout of a typical Piedmont’s farmstead.

The environment includes five main functional areas:

* **Unloading Area:** a garage where grapes are taken.
* **Grape Crushing Area:** a dedicated space for manually crushing harvested grapes.
* **Devatting Area:** an area where fermented wine is separated from grape pomace (skins, seeds, and other solid residues).
* **Storage Area:** a space for storing wine in traditional containers.
* **Tasting Area:** in the end, an area where users can drink and learn about flavours of wine.

The environment is initially represented using simple geometric shapes to establish its scale, layout, and spatial organisation.

Users can explore the environment through a first-person controller implemented with Unity's new Input System.

The scene is located at `Assets/Scenes/Blockout.unity`.
